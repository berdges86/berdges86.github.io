❓ Подробная инструкция

🛣️ Маршрут — добавление точек

  • Клик по карте — добавляет точку в конец маршрута (если режим «Добавление» включён).
  • Кнопка «➕ Добавление: ВКЛ/ВЫКЛ» — включает/выключает реакцию карты на клики.
  • Вставка в любое место — между строками точек есть кнопка ➕. Нажмите её — включится режим вставки. Следующие клики по карте будут вставлять точки именно в это место.
  • В режиме вставки индекс сдвигается после каждой точки — можно добавить подряд несколько точек в одну позицию.
  • Отмена режима вставки — Esc или кнопка «Отмена» в оранжевой плашке.

✋ Маршрут — редактирование

  • Перетаскивание точки на карте — схватите маркер и перенесите. Координаты обновятся.
  • Перестановка в списке — drag&drop строк за иконку ☰, либо кнопки ▲▼.
  • Удаление точки — крестик ✕ в строке.
  • Центрирование карты — клик по строке (не по кнопкам) — карта перелетит к точке.

📤 Экспорт

Кнопка «📤 Экспорт» открывает меню форматов. Экспортируются только точки (линия не сохраняется в файл, но остаётся на карте).

  • 💾 GeoJSON основной — стандартный формат для ГИС. FeatureCollection из Point.
  • 🔗 Яндекс.Карты основной — формирует ссылку rtext=, копирует в буфер и открывает в новой вкладке.
  • 🥾 GPX вспом. — для GPS-навигаторов, Strava, трекеров. Точки как <trkpt>.
  • 🌍 KML вспом. — для Google Earth / Google Maps. Каждая точка — Placemark с Point.
  • 📊 CSV вспом. — таблица index,lat,lon для Excel.
  • 📝 WKT вспом. — POINT (lon lat) построчно.
  • 📋 Текст (lat,lon) вспом. — простая строка lat,lon построчно.

Название файла — транслитерация названия маршрута (кириллица → латиница, пробелы → _).

📥 Импорт

Кнопка «📥 Импорт» открывает меню форматов. Импортируются только точки — линии игнорируются.

  • 📂 GeoJSON основной — берутся только Point. LineString/Polygon пропускаются.
  • 📎 Яндекс.Карты основной — вставьте ссылку с rtext= (из буфера, из адресной строки).
  • 🥾 GPX вспом. — точки <wpt> и <trkpt>. Линии трека не берутся.
  • 🌍 KML вспом. — только <Point><coordinates>. <LineString> пропускается.
  • 📊 CSV вспом. — lat,lon, разделитель запятая или точка с запятой. Первая строка-заголовок пропускается автоматически.
  • 📝 Текст (lat,lon) вспом. — вставьте координаты построчно в модальном окне.

Импорт добавляет точки к текущему маршруту. Для замены — кнопка «Заменить маршрут» в модале, либо сначала «🗑 Очистить».

📁 Слои GeoJSON

  • 📂 Загрузить файл — выберите один или несколько .geojson/.json.
  • 🔍 Сканировать папку — автоматически ищет все .geojson/.json в директории с HTML-файлом. Если листинг недоступен — пробует известные имена файлов.
  • Чекбокс — включить/выключить видимость слоя на карте.
  • 🔄 Инверсия XY — если точки отображаются «не там», возможно координаты в файле записаны как [lat, lon] вместо [lon, lat]. Кнопка меняет порядок.
  • 🔗 Яндекс.Карты — формирует ссылку на маршрут слоя, копирует в буфер и открывает в новой вкладке.
  • ✕ — удалить слой с карты.

Слои сортируются по id / properties.id / properties.name. Если точек больше одной — они соединяются линией (визуально, в экспорт не попадает).

🪟 Плавающие окна

  • Перетаскивание — схватите окно за шапку и переместите.
  • — — свернуть окно в шапку.
  • ✕ — скрыть окно. В углу экрана появится круглая кнопка для возврата.
  • Позиция и состояние окон сохраняются в браузере (localStorage) — после перезагрузки страницы окна останутся там же.

🤖 Геолокация

  • Кнопка 🤖 (правый нижний угол) — определяет ваше местоположение и ставит маркер на карте.
  • Требуется разрешение браузера на доступ к геолокации.

⌨️ Горячие клавиши

  • Esc — отменить режим вставки точки / закрыть модальное окно / закрыть меню экспорта-импорта.
